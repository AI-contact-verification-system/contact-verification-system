\## Overview

Management Solutions Group maintains a long-standing professional contact database at Microsoft Excel. Because contact information, job roles, communication preferences, and professional relationships change over time, manually validating and maintaining this information is inefficient and difficult to sustain. 



This capstone will deliver a proof-of-concept application that improves the contact-maintenance process through workflow automation and commercially available AI communication services. The system will import sponsor-approved contact data from Excel, allow administrators to select records for a campaign, request consent through email and/or SMS, track each consent decision, and begin an AI-assisted verification conversation only after explicit consent has been granted. 



The solution will retain a human-in-the-loop model. The AI component may collect and summarize updated information, but no data will overwrite the original contact database automatically. Instead, an administrator will review, approve, reject, or retain each proposed change before the system creates an updated Excel export. This design directly supports transparency, ethical AI use, auditability, and respect for communication preferences.
